================================================================================
实现的功能
================================================================================

✓ 启动前检查
  - 测速链接可用性检查 (HTTP HEAD请求)
  - 不可用时提示用户输入新链接
  - 新链接验证

✓ 并发配置
  - 启动时询问用户设置并发数
  - 默认值建议: 10
  - 支持自定义 (1-100范围)

✓ 输入处理
  - 支持CSV和TXT格式
  - 自动扫描常见默认文件
  - 支持用户自定义路径

✓ 处理流程
  1. 连通性测试: /cdn-cgi/trace 端点验证
  2. 并发测速: CloudflareST.exe 性能测试
  3. 地理位置查询: 多API备选机制

✓ 输出格式
  - CSV: IP | 端口 | 地区 | 国家 | 延迟(ms) | 下载速度(MB/s)
  - TXT: IP:端口#地区格式
  - JSON: 完整结构化数据
  - 所有文件带时间戳 (YYYYMMDD_HHMMSS)

✓ 用户交互
  - 清晰的中文提示和进度显示
  - 详细的错误处理和提示
  - 支持键盘中断 (Ctrl+C)

✓ 跨平台支持
  - Windows (BAT脚本)
  - Linux/Mac (Shell脚本)
  - 自动检测虚拟环境

================================================================================
使用方式
================================================================================

Windows:
  双击 "00-一键开始测试.bat"

Linux/Mac:
  bash "00-一键开始测试.sh"
  或
  python3 one_click_automation.py

交互步骤:
  1. 脚本检查测速链接可用性
  2. 询问并发数量设置
  3. 选择或指定输入文件
  4. 执行完整处理流程
  5. 输出结果文件
